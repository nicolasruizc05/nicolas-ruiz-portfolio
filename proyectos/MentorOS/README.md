# 🚀 MentorOS

## Descripción

MentorOS es una aplicación orientada a acompañar procesos de aprendizaje, ayudando a estudiantes y aprendices a organizar sus estudios, desarrollar hábitos y seguir rutas de formación.

## Objetivo

Crear una herramienta que permita planificar, registrar y mejorar procesos de aprendizaje mediante seguimiento y orientación.
